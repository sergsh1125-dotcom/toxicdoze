# ToxicDoze — база даних отруйних речовин та небезпечних хімічних речовин

## Призначення

**ToxicDoze** — вебзастосунок для довідкової роботи з концентраціями небезпечних хімічних речовин та рівнями **AEGL-1, AEGL-2, AEGL-3**.

Застосунок призначений для швидкого перегляду хімічних даних та порівняння фактичної концентрації речовини з відповідними пороговими значеннями для заданого часу впливу.

AEGL (Acute Exposure Guideline Levels) — рекомендаційні рівні гострого впливу для хімічних речовин у повітрі. EPA США визначає їх для п'яти періодів впливу: **10 хв, 30 хв, 1 год, 4 год та 8 год**. AEGL-1 відповідає менш тяжким, оборотним ефектам; AEGL-2 — серйозним або тривалим ефектам чи порушенню здатності залишити небезпечну зону; AEGL-3 — загрозливим для життя ефектам або смерті. citeturn0search0turn0search6

> **Важливо:** AEGL є орієнтирами для аварійного планування та реагування, а не автоматично юридично обов'язковими нормативами. Для конкретної ситуації необхідно враховувати чинні нормативні вимоги та відповідні хімічно-специфічні технічні документи. citeturn0search0

### `index.html`

- вибір речовини;

## Робота з AEGL

Для обраної речовини таблиця показує одразу три рівні:

| Рівень | Значення |
|---|---|
| AEGL-1 | нижчий рівень гострого впливу |
| AEGL-2 | серйозні наслідки / порушення здатності залишити зону |
| AEGL-3 | загроза життю / смерть |

Для кожного рівня використовуються п'ять періодів:

- **10 хв**
- **30 хв**
- **60 хв**
- **240 хв (4 год)**
- **480 хв (8 год)**

Якщо для конкретного рівня значення не рекомендоване, у таблиці використовується позначення **NR (Not Recommended)**.

EPA офіційно публікує AEGL-значення за назвою речовини або CAS-номером, а також окремі технічні документи для конкретних хімічних речовин. citeturn0search6

## Фактична концентрація

У застосунку передбачений окремий блок:

**ФАКТИЧНА КОНЦЕНТРАЦІЯ**

Оператор задає:

1. фактичне значення концентрації;
2. одиницю вимірювання:
   - **мг/м³**
   - **ppm**
3. час впливу:
   - 10 хв;
   - 30 хв;
   - 60 хв;
   - 240 хв;
   - 480 хв.

Після натискання **«ВИЗНАЧИТИ РІВЕНЬ ВПЛИВУ»** програма порівнює фактичну концентрацію з AEGL-1, AEGL-2 та AEGL-3 для обраного часу впливу.

### Конвертація одиниць

Якщо фактичне вимірювання задане в одиниці, відмінній від одиниці AEGL у базі, програма намагається привести значення до одиниці, у якій виконується порівняння.

Для перерахунку між ppm та мг/м³ використовується молекулярна маса речовини та стандартне наближення для газів:

```text
мг/м³ = ppm × MW / 24,45
ppm   = мг/м³ × 24,45 / MW
```

Якщо необхідні дані для безпечної конвертації відсутні або одиницю AEGL неможливо однозначно визначити, автоматичне порівняння не виконується.

## Джерела AEGL

Основним зовнішнім джерелом AEGL є **U.S. Environmental Protection Agency (EPA), Acute Exposure Guideline Levels Program**.

Офіційні сторінки EPA:

- Acute Exposure Guideline Levels: https://www.epa.gov/aegl
- About AEGLs: https://www.epa.gov/aegl/about-acute-exposure-guideline-levels-aegls
- Access AEGL Values: https://www.epa.gov/aegl/access-acute-exposure-guideline-levels-aegls-values
- Process for Developing AEGLs: https://www.epa.gov/aegl/process-developing-acute-exposure-guideline-levels-aegls
- Standing Operating Procedures: https://www.epa.gov/aegl/standing-operating-procedures-developing-acute-exposure-guideline-levels-aegls-hazardous

EPA зазначає, що AEGL розробляються за формалізованою процедурою, із використанням наукових даних та технічних документів; для окремих речовин статус може бути **Final, Interim, Proposed або Holding Status**. citeturn0search2turn0search3turn0search6

## Важливий принцип роботи з базами

Файли:

```text
data/toxic_agents_v2.js
data/hazardous_chemicals_v2.js
```

є **джерелом даних**, а `index.html` — інтерфейсом та логікою їх використання.

Тому при подальшій розробці бажано:

- не дублювати значення AEGL безпосередньо в `index.html`;
- не змінювати дані вручну в декількох місцях;
- оновлювати бази окремими файлами;
- зберігати походження та статус значень (Final / Interim / Proposed), якщо ці поля присутні в джерелі.

### Наступні етапи

Планується розвиток у напрямку системи підтримки прийняття рішень щодо хімічної обстановки:

1. кольорова індикація результату;
2. відображення результату на карті;
3. введення реальних точок хімічної розвідки;
4. прив'язка фактичної концентрації до координат;
5. класифікація точок за AEGL;
6. побудова ізоліній за **фактичними**, а не прогнозними вимірюваннями;
7. інтеграція модуля з картою фактичної хімічної обстановки.
